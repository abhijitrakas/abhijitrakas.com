# abhijitrakas.com

Personal site built with [Astro](https://astro.build).

## Editing

- **Your text (bio, “Beyond work”, skills, links):** `src/data/site.ts`. The page, `/llms.txt`, the web manifest and the search-engine data are all generated from this one file.
- **Phrases that become links** (like “rtCamp”): `autolinks` in the same file.
- **Colors, fonts, spacing:** `src/styles/global.css`
- **Portrait:** `src/assets/portrait.webp`. The page blends its white paper into the background, so keep a white background with a soft fade at the bottom.
- **Logo and icons:** `src/assets/logo.svg` (page), `public/favicon.svg`, `public/favicon.ico`, `public/apple-touch-icon.png`, `public/icon-192.png`, `public/icon-512.png`
- **Link-preview image:** `public/og.jpg` (1200×630)

## SEO and AI agents

| URL | What it is |
| --- | --- |
| `/robots.txt` | Allows all crawlers and points to the sitemap |
| `/sitemap-index.xml` | Generated by `@astrojs/sitemap` from the pages in `src/pages` |
| `/llms.txt` | Plain Markdown summary for AI agents ([llmstxt.org](https://llmstxt.org)) |
| `/site.webmanifest` | Name and icons for Android home screens |
| `/404.html` | Custom not-found page (marked `noindex`) |

The home page also carries `ProfilePage` + `Person` structured data (JSON-LD) and Open Graph / Twitter tags, all set in `src/layouts/Base.astro`.

## Deployment

Every push to `main` builds the site and publishes it to GitHub Pages
(`.github/workflows/deploy.yml`). You can also run it by hand from the repo's **Actions** tab.

One-time setup:

1. **Repo → Settings → Pages:** set **Source** to "GitHub Actions" and **Custom domain** to `abhijitrakas.com`.
   (With Actions deploys, GitHub reads the domain from this setting, not from a `CNAME` file.)
2. **DNS for `abhijitrakas.com`:** remove the existing `A` record(s), then add:

   | Type    | Name  | Value                                                                       |
   | ------- | ----- | --------------------------------------------------------------------------- |
   | `A`     | `@`   | `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`  |
   | `AAAA`  | `@`   | `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153` |
   | `CNAME` | `www` | `abhijitrakas.github.io`                                                    |

3. Once DNS has propagated and the certificate is issued, tick **Enforce HTTPS** in the same Pages settings.

GitHub Pages needs a public repo on the free plan. Private repos need GitHub Pro or higher.
